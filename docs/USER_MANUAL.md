## المتطلبات

### الجهاز

- **أندرويد 8.0+** (API 26)
- **معمارية**: arm64-v8a (99% من الأجهزة الحديثة)
- **Vulkan 1.1+** — تحقّق في الإعدادات → التشخيص
- **مساحة فارغة**:
  - SC 1.1: ~1 GB
  - SC HD: ~1.7 GB
  - SC Extreme: ~2 GB

### نسخة اللعبة (شرعية)

تحتاج نسخة شرعية من Stronghold Crusader. الأشكال المدعومة:

| المصدر | الحالة |
|--------|--------|
| GOG.com (offline installer) | ✅ موصى به |
| Steam (Stronghold Crusader HD) | ✅ |
| CD الأصلي (2002) | ⚠️ يحتاج iso extraction |
| Disc image (.iso) | ✅ عبر 7z extraction |

**ملاحظة قانونية**: لا يوزّع StrongholdDroid أي ملفات لعبة. المستخدم مسؤول
حصرياً عن توفير نسخة شرعية.

## التثبيت الأولي

### 1. تثبيت APK

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

أو من خلال مدير الملفات: انقر على ملف APK واختر "تثبيت".

### 2. أول تشغيل

عند فتح التطبيق لأول مرة:

1. يظهر شاشة الترحيب مع 3 تبويبات: **المكتبة / الأداء / الإعدادات**
2. في تبويب الإعدادات → التشخيص → اضغط **تحقق من الباينري**
3. يجب أن يظهر: "All binaries present ✓"

إذا ظهر خطأ، يرجى الرجوع إلى [BUILD_GUIDE.md](BUILD_GUIDE.md).

## تثبيت ملفات اللعبة

### الطريقة 1: من مجلد جاهز (الأسهل)

1. انسخ مجلد Stronghold Crusader من حاسوبك إلى الهاتف
2. في StrongholdDroid: الإعدادات → المكتبة → **تثبيت من مجلد**
3. اختر المجلد الأصل (الذي يحتوي على `Stronghold_Crusader.exe`)
4. انتظر حتى يتم الكشف عن الإصدار تلقائياً
5. سيُنسخ المجلد إلى `<filesDir>/games/<slug>/drive_c/`

### الطريقة 2: من GOG installer

1. انسخ `setup_stronghold_crusader_hd_*.exe` إلى `/sdcard/Download/`
2. في StrongholdDroid: المكتبة → اختر SC HD → **تثبيت من installer**
3. التطبيق سيشغّل الـ installer تحت Wine ويستخرج الملفات تلقائياً
4. هذه الطريقة أبطأ (~10 دقائق) لكنها تضمن التطابق الكامل مع نسخة GOG

### الطريقة 3: من CD/ISO

1. استخرج ملفات الـ ISO محلياً عبر 7z أو WinRAR
2. استخدم الطريقة 1 مع المجلد المستخرج

## التشغيل

1. افتح التطبيق → تبويب **المكتبة**
2. اضغط على بطاقة اللعبة المطلوبة
3. اضغط **تشغيل**
4. ستظهر شاشة سوداء لمدة 5-15 ثانية (تحميل Wine)
5. تظهر شاشة اللعبة الكاملة مع طبقة التحكم اللمسية

**للخروج**: اضغط زر الرجوع مرتين خلال ثانية واحدة (لتفادي الخروج
العرضي خلال المعارك).

## نظام التحكم

### العناصر على الشاشة

```text
┌──────────────────────────────────────────────────────────────┐
│ [B] [M] [H] [F1] [Esc]    ← سطر أوامر علوي                  │
│                                                              │
│                          ●  ← نقطة الماوس الافتراضي          │
│                                                              │
│                       (منطقة لمس حرة)                         │
│                                                              │
│                                                              │
│ [⌨]                                       ← زر لوحة المفاتيح │
└──────────────────────────────────────────────────────────────┘
```

### إيماءات اللمس

| الإيماءة | الإجراء في اللعبة |
|----------|-------------------|
| نقرة واحدة | زر يسار للماوس (نقر واحد) |
| نقرتان متتاليتان | زر يسار مزدوج (اختيار سريع) |
| سحب بإصبع واحد | زر يسار مستمر (تحديد منطقة) |
| سحب بإصبعين | تحريك الكاميرا (pan) |
| قرص بإصبعين (pinch) | تكبير/تصغير الخريطة |
| لف بإصبعين (twist) | تدوير الكاميرا (Q/E) |
| نقر بإصبعين معاً | زر يمين (قائمة سياق / إلغاء تحديد) |
| ضغط مطوّل (500ms+) | زر وسط (تركيز على minimap) |
| نقر بثلاث أصابع | فتح القائمة (Esc) |

### أزرار سطر الأوامر

| الزر | الفعل في اللعبة |
|------|-----------------|
| **B** | فتح قائمة البناء |
| **M** | فتح نقطة المرتزقة |
| **H** | معلومات السيد (Lord) |
| **F1** | اختيار مجموعة سريعة 1 |
| **Esc** | فتح القائمة / إيقاف مؤقت |

### تخصيص الإيماءات

الإعدادات → التحكم:

- **حساسية الماوس**: 0.1-5.0 (الافتراضي 1.0)
- **التمرير عند الحواف**: تشغيل/إيقاف
- **قفل السحب**: تحويل نقرة + سحب قصير إلى LMB مستمر
- **تخطيط لوحة المفاتيح**: QWERTY / AZERTY / QWERTZ

## الإعدادات

### الرسوميات

| الخيار | الوصف |
|--------|------|
| DXVK (Vulkan) | الأمثل لـ SC HD/Extreme. تعطّل تلقائياً على الأجهزة بدون Vulkan 1.1 |
| gl4es (OpenGL ES) | للمسار الاحتياطي على الأجهزة الضعيفة |
| تحجيم ديناميكي | خفض الدقة تلقائياً للحفاظ على FPS ثابت |
| الإطار المستهدف | 30 / 45 / 60 |

### الأداء

- **مراقب الحرارة**: نشط افتراضياً. خفض الدقة عند 75°C+، وقف عند 85°C+
- **خزّان الذاكرة**: يضمن عدم تسرّب ذاكرة Wine في الجلسات الطويلة
- **حفظ الحالة التلقائي**: كل 10 دقائق، في الخلفية

---

## الجلسات الطويلة

للحفاظ على الاستقرار في جلسات 2+ ساعة:

1. **اشحن الهاتف قبل البدء** (الجهاز يستهلك ~3 W نشط)
2. **خلع الحافظة الواقية** (تساعد على التبريد)
3. **ضع الهاتف على سطح صلب** (تجنب السجاد/الورود)
4. **راقب الحرارة** في تبويب الأداء
5. **حفظ الحالة كل 30 دقيقة** (زر "حفظ الحالة الآن")

### مستويات الحرارة

| المستوى | الحرارة | الإجراء |
|---------|---------|---------|
| 0 (طبيعي) | <65°C | لا شيء |
| 1 (دافئ) | 65-75°C | خفض الدقة درجة واحدة |
| 2 (ساخن) | 75-85°C | خفض الدقة للحد الأدنى، تقليل الصوت 3 dB |
| 3 (حرج) | >85°C | حفظ الحالة + طلب إيقاف لطيف |

## حفظ الحالة

### حفظ يدوي

في تبويب الأداء → **حفظ الحالة الآن**.

أو خلال اللعبة: اضغط زر الرجوع طويلاً (≥800 ms) — يحفظ الحالة ثم يفتح
حوار الخروج.

### حفظ تلقائي

كل 10 دقائق، يحفظ التطبيق حالة في الخلفية (لا يوقف اللعبة).

عند خروج Android من التطبيق (نظام منخفض الذاكرة مثلاً): يتم حفظ الحالة
متزامناً خلال 5 ثوان.

### الاستعادة

عند تشغيل لعبة موجودة لها save-state:
- يظهر زر **استعادة الحالة** بجانب **تشغيل**
- اضغطه لتشغيل Wine في وضع الـ restore — يصل إلى حالة اللعبة المحفوظة
  خلال 3-5 ثوان (بدون logo/menu)

### عدد الـ slots

كل لعبة تدعم 10 slots. الحفظ الأقدم يُحذف تلقائياً عند تجاوز العدد.

## دعم Gamepad

### الأجهزة المدعومة

- Xbox One / Series controllers (Bluetooth)
- DualShock 4 (PS4) — Bluetooth
- DualSense (PS5) — USB أو Bluetooth
- 8BitDo SN30 Pro+
- Razer Kishi / GameSir X2 (USB-C)

### الربط الافتراضي

| المدخل | الفعل |
|--------|------|
| Left stick | حركة الماوس الافتراضي |
| Right stick | تحريك الكاميرا (أسهم) |
| D-pad | WASD (للكاميرا أيضاً) |
| A | زر يسار للماوس |
| B | فتح قائمة البناء (B) |
| X | إيقاف مؤقت (Space) |
| Y | معلومات السيد (H) |
| L1 | تدوير الكاميرا يسار (Q) |
| R1 | تدوير الكاميرا يمين (E) |
| L2 | اختيار مجموعة 1 (1) |
| R2 | اختيار مجموعة 2 (2) |
| Select | فتح القائمة (Esc) |
| Start | إيقاف (P) |
| Left stick click | F1 |
| Right stick click | F2 |

### تخصيص الربط

الإعدادات → التحكم → **تكوين Gamepad** — اضغط على أي زر لإعادة ربطه.

## أسئلة شائعة

### هل يدعم اللعبة الأصلية بدون HD؟

نعم — اضغط على SC 1.1 في المكتبة. نفس طبقة التحكم، لكن ممر رسومي مختلف
(wined3d بدل DXVK لأن DXVK لا يدعم DirectDraw).

### هل أحتاج اتصال إنترنت؟

لا — التطبيق يعمل بالكامل دون اتصال بعد التثبيت الأولي.

### هل يمكنني نقل save-states بين الأجهزة؟

نعم — موجودة في `<filesDir>/saves/<slug>/`. انسخ الملفات `.bin` إلى جهاز
آخر. لاحظ أن الحالة تشمل Wine process state (مع PID!) لذا الاستعادة على
جهاز مختلف قد تترك بعض الحالة غير مستعادة — استعادة العمل على نفس الجهاز
الأصلي.

### هل يدعم الـ landscape فقط؟

نعم — اللعبة مصممة لـ landscape. اضغط على زر تدوير الشاشة في الهاتف
للأفقي قبل التشغيل.

### ما الفرق بين SC HD و SC Extreme؟

- SC HD: نسخة 2014 المُحدَّثة بدقة 1920×1080
- SC Extreme: نسخة 2014 مع إضافة وحدات كثيرة (تصل لـ 5000+)، أكثر ضغطاً
  على الأداء
